  Project Structure

  QuranSub/
  ├── .venv/                  # Virtual environment (all deps installed)
  ├── config.yaml             # Configurable subtitle styling, model settings
  ├── requirements.txt
  ├── run.py                  # CLI entry point
  ├── src/
  │   ├── audio.py            # Step 1: Extract audio via ffmpeg
  │   ├── transcribe.py       # Step 2: Whisper ASR with word timestamps
  │   ├── quran_data.py       # Step 3: Load CSV (6236 ayahs)
  │   ├── match.py            # Step 4: Sequence alignment to identify ayahs
  │   ├── subtitle.py         # Step 5: Generate .srt + .ass files
  │   ├── render.py           # Step 6: Burn ASS subtitles into video
  │   └── pipeline.py         # Orchestrates all steps
  ├── data/
  │   └── ben_quran_with_tafsir.csv
  └── output/                 # Generated outputs land here

  Usage

  # Activate venv first
  .venv\Scripts\activate

  # Full pipeline (auto-detects surah)
  python run.py full input_video.mp4

  # With surah hint for faster/better matching
  python run.py full input_video.mp4 --surah 76

  # Individual stages for debugging
  python run.py extract-audio video.mp4
  python run.py transcribe output/audio.mp3
  python run.py match output/transcription.json --surah 6
  python run.py subtitle output/matched_segments.json
  python run.py render video.mp4 --subtitle output/subtitles.ass

  Verified

  - CSV loads all 6236 ayahs correctly
  - Arabic normalization strips diacritics, ayah markers, and normalizes letter variants
  - Matching tested with notebook's sample data — correctly identified Surah 6, Ayahs 31-32 with proper timestamp boundaries, both with and without surah hint  
  - Subtitle styling (position, font, color, size) is configurable in config.yaml

  Prerequisites

  - ffmpeg must be installed and on PATH (for audio extraction and video rendering)
  - A CUDA GPU is recommended for transcription speed, but CPU fallback works
